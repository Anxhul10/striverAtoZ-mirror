# Striver's A2Z Sheet --- Personal Tracker

**Completely free and open source.** This community project brings back
a personal-tracker experience inspired by the old Striver A2Z website.
It is an independent project and is not the official TakeUForward
website.

The tracker lets you follow topics and subtopics, mark problems as
completed, add notes, and keep problems for revision. It also supports
**exporting and importing your progress** as a JSON file.

> **Articles are included, but the collection is still being updated.**
> You can help by writing an article and submitting a pull request (PR).

## Save and restore your progress

Progress is saved automatically in your browser.

### Save a backup

1.  Open the tracker.
2.  Click **Export**.
3.  Keep the downloaded `striver-a2z-progress.json` file somewhere safe.

### Load a saved backup

1.  Open the tracker in the browser.
2.  Click **Import**.
3.  Select your saved `striver-a2z-progress.json` file.

Importing a file replaces the progress currently saved in that browser.
Export your current progress first if you want to keep a backup.
